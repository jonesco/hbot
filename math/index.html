Slope = rise over run

Walk from one point to the other like a platformer. First go sideways, then go up or down.

Run is how far you go sideways. Rise is how far you go up (or down).

Drag the yellow points. Watch the numbers change.

Four kinds of ramps

Always read a line left to right, like you're running through a level.

Uphill is positive. Downhill is negative. Flat ground is zero. A straight-up wall is undefined, because you'd be dividing by zero run, and that's not allowed.

Bigger number = steeper. A slope of 5 is a cliff. A slope of 1/4 is a lazy hill.

BIG IDEA
Y'S ON TOP.
SAME ORDER BOTH TIMES.

Rise on top because y goes up and down. Whichever point you start with on top, start with it on the bottom too. Wrap negatives in parentheses.

No graph? Use the formula.

The formula counts the boxes for you. Same rise over run, just with numbers. m is the letter math uses for slope.

Y's go on top. y is up and down, and rise is up, so it goes up top. X's go on the bottom.

The little ₁ and ₂ are just name tags. x₂ means "the x from point 2." They don't mean multiply or square anything.

A point is always (x, y). First number is x, second is y. Alphabetical.

    Traps to dodge

    These are where almost everyone loses points. Know them and you're ahead.

    TRAP 1: THE FLIP

    Putting x's on top. With (1, 2) and (4, 8) you'd get 3/6 = 1/2 instead of 2.

    Y on top. Always.

    TRAP 2: MIXED ORDER

    Whichever point you start with on top, start with it on the bottom too.

    (8 − 2) / (1 − 4) = −2 WRONG

    TRAP 3: DOUBLE NEGATIVE

    Points (−1, 4) and (3, −4). Wrap negatives in parentheses.

    top: −4 − 4 = −8
    bottom: 3 − (−1) = 3 + 1 = 4
    m = −8/4 = −2

    Minus a negative turns into plus.

    TRAP 4: ZEROS

    0 on top: slope is 0. Flat.

    0 on bottom: undefined. Can't divide by zero. It's a wall.

    Missing coordinate

    Sometimes a point has a letter in it, like (2, u). They give you the slope, so it's a puzzle. Work backward.

    slope = topbottom
    LETTER ON TOP (A Y IS MISSING)

    Work out the bottom first. Then:

    top = slope × bottom

    LETTER ON BOTTOM (AN X IS MISSING)

    Work out the top first. Then:

    bottom = top ÷ slope

    WHEN THE SLOPE IS A FRACTION

    Nothing changes. A slope like 3/5 already is rise over run: rise 3, run 5.

    Times a fraction: multiply by the top, divide by the bottom.
    Divided by a fraction: flip it and multiply.

    −3 ÷ 3/5 = −3 × 5/3 = −5

    Then solve the little equation for the letter. Last move: plug it back in to check.
